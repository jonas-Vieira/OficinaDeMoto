# 🏍️ OficinaDeMoto

Sistema de gerenciamento de oficina de motocicletas desenvolvido em Java, com foco na aplicação prática dos conceitos de Programação Orientada a Objetos (POO).

## 📌 Sobre o projeto

O OficinaDeMoto é um projeto pessoal desenvolvido para praticar Java e simular a organização de uma oficina de motocicletas.

A proposta é permitir o gerenciamento de clientes, motocicletas, serviços e ordens de serviço, utilizando uma estrutura organizada em classes e responsabilidades.

## ⚙️ Funcionalidades

- Cadastro e gerenciamento de clientes.
- Cadastro e gerenciamento de motocicletas.
- Registro de serviços oferecidos pela oficina.
- Organização de ordens de serviço.
- Controle de status das ordens de serviço.

*Observação: funcionalidades em desenvolvimento podem sofrer alterações.*

## 🧠 Conceitos aplicados
